Required Workflow for Every Task

  1. Open main.
    git switch main
  2. Get the latest changes.
    git pull origin main
  3. Create a feature branch.
    git switch -c workflow
  4. Edit and test the assigned file in VS Code.
  5. Check the branch and files.
    git branch
git status
  6. Review line changes.
    git diff
  7. Stage the change.
    git add .
  8. Create a meaningful commit.
    git commit -m "Add assigned page content"
  9. Push the feature branch.
    git push -u origin workflow
  10. Create a pull request on GitHub.
  11. Ask another member to review before merging.
  12. Update local main after the merge.
    git switch main
git pull origin main

Team Rule

Pull first, create a branch, edit, review, stage, commit, push, request review, merge, and pull the updated main branch.
