Version Control and Team Collaboration

This website explains how our group uses Visual Studio Code, Git, and GitHub to work on one project without overwriting another member's work.

Development Tools

Visual Studio Code

VS Code is the local workspace where we create files, edit code, open the terminal, and view Git changes.

Git

Git is the local version control system that tracks changes, creates commits, and manages branches.

GitHub

GitHub stores the remote repository online so members can share code, review pull requests, and mergework.
