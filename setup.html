Git Installation and Repository Setup

Home Git Setup Team Workflow

1. Check Git Installation

git --version

A Git version number confirms that Git is installed.

2. Configure Git Identity

git config --global user.name "Kalvin Dave Ramos"
git config --global user.email "ramoskalvindave51@gmail.com"
git config --global --list

The configured name and email appear in the commit history.

3. Initialize the Group Project

git init
git status
git add .
git commit -m "Create initial project structure"

Only the group leader performs the initial repository setup.

4. Connect the Remote Repository

git branch -M main
git remote add origin https://github.com/kalvindave/repository.git
git remote -v
git push -u origin main

The remote named origin connects the local project to GitHub.

Important

Never publish passwords, verification codes, personal access tokens, recovery codes, or other secrets in a repository.
